# Reference Audit Note

All references added or emphasized by the final literature-strengthening pass were checked against identifiable publication metadata. No citation was added solely because its title sounded relevant.

The audit deliberately favors directly relevant peer-reviewed IEEE PC-FMCW work and authoritative ISAC/V2X background over a large but weakly connected bibliography. References are used to delimit prior art and support model/provenance choices; they are not used to imply that this repository performed hardware experiments reported by other authors.
