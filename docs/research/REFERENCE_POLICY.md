# Final Citation Policy

For submission-facing text:

1. Cite primary peer-reviewed literature for technical PC-FMCW claims whenever available.
2. Use surveys for broad ISAC context, not as substitutes for direct PC-FMCW prior art.
3. Use manufacturer documentation only for declared hardware/profile provenance.
4. Do not describe external experimental results as measurements produced by this repository.
5. Do not use a citation to expand a claim beyond the source's demonstrated scope.
6. Avoid categorical priority language unless a systematic review establishes it.
7. Preserve DOI and bibliographic metadata so reviewers can resolve each source directly.
