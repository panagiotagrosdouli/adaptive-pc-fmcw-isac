# Paper 1 Submission Plan

## Target story

Paper 1 is the physics/configuration paper. Its novelty claim is deliberately narrow: a PC-FMCW vehicular adaptation problem should expose deterministic waveform capability boundaries and gate physically unsupported actions before stochastic QoS optimization.

## Required final evidence before submission

- IEEEtran compilation with no unresolved citations/references or duplicate labels.
- All numerical profile values cross-checked against `artifacts/stage7/pilot_validation.json` and profile configuration files.
- All pilot results labelled as simulation evidence.
- Figure/table provenance checked.
- Citation list independently verified against DOI/publisher metadata.
- Final PDF visually inspected for clipping and unreadable figures/tables.
- Paper 2/v2.1 reliability evidence excluded unless explicitly used as motivation; no cross-paper result laundering.

## Planned final figure set

1. System architecture and separation of communication/sensing paths.
2. Profile capability comparison: range resolution, positive-IF range, velocity resolution, and unambiguous velocity.
3. Parking-profile sensing RMSE versus IF SNR.
4. DBPSK BER simulation versus AWGN theory.
5. Range--velocity physical-feasibility map derived from profile limits.

Only figures supported by the repository evidence will be included in the final submission.
