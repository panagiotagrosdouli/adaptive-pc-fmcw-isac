# Frozen Publication V2.1 Evidence Bundle

This directory is the repository index for the frozen publication-v2.1 evidence generated by GitHub Actions run `33967030983` at commit `1b2100c11b6d4a7b6213777fd2da85e22601154b`.

Committed files:

- `FINAL_RESULTS.json` — compact machine-readable aggregate results, Wilson lower bounds, paired bootstrap comparisons, Pareto output, and structural sanity gate.
- `E9_E11_RESULTS.json` — compact machine-readable feasible-region and ablation results with the E9 raw-mean statistical caveat preserved.
- `PROVENANCE.json` — workflow run, frozen commit, GitHub Actions artifact IDs/names, SHA-256 digests, and evidence classes.

Publication-facing interpretation is in `docs/PUBLICATION_V2_1_RESULTS.md`.

The complete raw result bundles are intentionally retained as GitHub Actions artifacts rather than duplicated as a 46 MB JSON file in Git history. They are still on GitHub and are cryptographically tied to this repository through the artifact IDs, run ID, frozen commit, and SHA-256 digests in `PROVENANCE.json`.

Evidence is simulation evidence, not hardware measurement.
